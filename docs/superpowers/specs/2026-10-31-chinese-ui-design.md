# 中文界面设计

## 目标

将知识库助手插件的默认用户界面改为简体中文，同时保持现有功能、数据格式和安全流程不变。

## 范围

需要翻译的内容包括：

- ItemView 标题和四个一级页签。
- R1 规则编辑器的三个子页签、字段名称、按钮和状态提示。
- 概览页的索引状态、操作按钮和错误提示。
- AI 整理页的范围选择、任务选择、上传预览、确认和建议状态。
- 每日回填页的阶段说明、每日/每周操作和结果状态。
- 设置页的分组、字段名称、描述和隐私提示。
- Ribbon 图标名称、命令名称、Notice 和异常提示。

## 不变内容

- 命令 ID、插件 ID、设置字段键和持久化数据结构。
- 规则文档中的 YAML 键、状态值、动作值和路径。
- AI 请求 JSON 结构与 API 协议。
- 本地检查、上传确认、diff 预览、冲突检测和用户确认后的文件操作。
- README 中的技术命令和配置字段名；说明文字可补充中文。

## 实现方式

新增集中式中文文案模块，例如 `src/i18n/zh-CN.ts`，按页面和功能分组导出文案。视图和设置页只引用文案模块，不再散落硬编码英文。首版不增加语言切换选项，默认始终使用简体中文。

文案模块只负责显示文字，不承担业务逻辑。技术值如 `draft`、`reviewing`、`verified`、`stale` 和命令 ID 保持原值；需要展示给用户时通过文案映射转换为中文。

## 验证

- TypeScript 构建通过。
- 现有全部测试继续通过。
- lint 无 error。
- 在真实 Obsidian 中确认四个页签、设置页、Ribbon 和命令面板默认显示中文。
- 确认中文化不改变规则保存、索引检查、AI 上传确认和每日回填行为。
